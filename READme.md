# Personal Mini-Toolkit

## About the Project

The Personal Mini-Toolkit is a Python program that provides three useful tools through a menu-driven interface.

### Tools

1. **Simple Calculator:** Performs addition, subtraction, multiplication and division.
2. **To-Do List:** Allows users to add, view and remove tasks.
3. **Number Checker:** Checks whether a number is positive, negative or zero.

## How to Run

1. Make sure Python is installed.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:

`py toolkit.py`

## Reflection

The hardest part of this project was understanding how to organise the menu and make it return after each tool. The nested loops in the To-Do List took the most time to understand. I also had to make sure users could return to the main menu without ending the entire program. Testing each tool helped me understand how loops, lists and conditionals work together. I learned how to build a menu-driven program using Python. With one more week, I would add more tools and improve the program by saving tasks so they are not lost when the program closes.
